无负担地记录日常，从原文中发现有依据的兴趣、恢复与探索线索。
不要求文采，不把记录数量当成长评分，不强行解释成积极结果。

## 开发与验证

需要 Node.js 20 或更新版本；现有应用不需要安装 npm 依赖。

```sh
npm start
npm run start:prototype
npm run start:test
npm test
```

启动命令分别运行。常规页面端口已占用时，以 `PORT` 指定其他端口。
`start:test` 单独启动隔离体验稿，输出实际的临时测试地址；不复用 4174/4175，
不迁移或清空用户数据。新端口隔离浏览器 origin；每次仍须核对页面没有私人记录。
自动测试不调用真实 Copilot；其中接口测试需要允许监听本机测试端口。
`npm run start:test -- --font-failure` 在独立测试页面故意让字体资源返回 404，
用于真实浏览器验证回退字体；不会改变默认体验稿或主应用。
真实模型测试另见 `COPILOT.md`，会使用账号额度，默认不运行。
自动检查不能代替真实浏览器、手机和用户试用验收。

## 项目边界

本目录是共享工作区，Git 只追踪 `.gitignore` 白名单中的寻光日记文件。
家庭学习文件、临时输出、截图、用户数据、凭证和日志不进入版本库。
新文件需明确加入白名单；不要为方便使用 `git add -f` 绕过保护。
当前代码已推送到 GitHub 的 xiaocliuAI/seeking-light；没有发布应用。
网页验收任务已建成 issues，用户已授权启动 Agent；#1/#3 已经 PR 测试并合并。
#2 的视口、键盘与字体故障已部分验收，完整缩放、真机及用户体验评价仍待确认。

## PR 验收流程

用户已授权 Agent 按 issue 依赖推进：功能分支 -> PR -> 自动检查与实际验收 ->
主 Agent 审查 -> 通过后合并。不能因自动检查结束就关闭未验收的任务。
GitHub Actions 只运行静态/行为替身/本机 API 检查，不是远程浏览器或真实模型测试。
真实模型、系统权限和人工审美验收仍各自需要满足对应门槛。
