# flomo 批量导入

日期：2026-11-07。范围：4175 原文与旁注体验稿，不是 4174 正式应用替换。

## 使用

1. 在 flomo 设置 - 账号详情导出全部记录。官方说明导出格式为 HTML。
2. 如果得到 ZIP，解压后选其中的 HTML。顶部导入图标可选择一个或多个 HTML。
3. 查看总条数、新增、重复、日期范围及前三条预览。此时没有写入。
4. 存在无效时间、无文字或图片附件时，先确认提示，再导入可用的文字记录。
5. 确认后进入回看。旧年份会显示完整年份，可按日期筛选；每页最多 50 条。

记录只保存在当前浏览器、当前 origin 的体验稿存储中，不上传、不登录 flomo、
不调用模型。原导出文件应继续保留；本功能不提供跨设备同步或正式版迁移。
导入内容不会参与固定示例 Findings。真实 Findings 仍需要独立开发和授权。

## 格式与边界

- 支持官方 HTML 中的 `.memo` / `.time` / `.content` 结构。
  官方帮助没有公开版本化文件 schema；其他结构拒绝导入，不猜测原日期。
- 时间按文件中的本地日期保留，支持 YYYY-MM-DD HH:mm[:ss]，秒位保留。
  非法日期与时间计入未导入项，不使用今日日期替代。
- 富文本转换为纯文字：段落和换行、列表、代码缩进、文字标签保留；
  粗体、字体颜色等格式不搬入。超链接保留文字及 HTTP(S)/mailto 地址。
- #标签保留在正文中，也作为 tags 元数据保存；尚无独立标签筛选 UI。
- 图片、音频、视频和附件不搬入；纯图片记录没有可用文字，不导入。
  原 HTML 和附件目录是原始备份，不得因本次文字导入而删除。
- 重复依据相同日期、时间及转换后文字，包含文件内和已导入记录的重复。
  同一秒、同样文字的两条记录会视为重复；正文或时间变了会作为新记录。
- 总 HTML 上限 20 MB、40,000 条；超过会拒绝，建议按日期分批导出。
  浏览器存储配额可能更小；写入失败整批不导入，不做静默部分写入。
- 确认前检查存储快照；另一标签改了数据则拒绝，要求刷新后重新预览。
  不覆盖原日记、投入/感受、回访或未提交书写草稿。
- 导出 HTML 在脱离页面的 template 中解析，不执行或挂载 HTML、脚本或图片。
  预览与正文通过 textContent 呈现，没有把导出内容插入活动页面。

## 验证

- `npm test`：新增 strict timestamp、SHA-256 ID、去重、文字提取和大小限制；
  应用行为替身验证预览/取消不写入、配额失败整批回滚/重试、保留草稿/日期/标签、
  重导入、跨标签变化拒绝与附件提示确认。替身不是 HTML 引擎或真实浏览器。
- 实际 IAB 隔离入口 127.0.0.1:50767，仅用虚构文件测试。五条记录包含重复、
  无效闰日、纯图片和恶意脚本；结果新增 2、重复 1、无效 1、无文字 1。
  确认后刷新，2024-02-29 记录可按日期找到；重选同文件新增 0、重复 3。
- 预览中未出现活动 img，攻击脚本没有设置 body 标记；不把静态代码测试
  当成完整浏览器网络审计。没有读取用户真实导出文件。
- 2,500 条生成的虚构 HTML 能完成实际预览；320x740 页面宽和文档宽均 320，
  弹窗 clientWidth/scrollWidth 均 282。弹窗可滚动，确认按钮在内容末尾。
  大批量确认、分页及刷新由 PR 后复验记录补充到 PR 评论。
- 实际截图位于 ignored `output/test-results/flomo-*.jpg`，不进入 Git。
  真实手机软键盘、不同 flomo 导出版本及用户真实文件尚未验收。
