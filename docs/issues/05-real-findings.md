## 目标与前置
新设计迁移完成后，将真实 Copilot 与精确原文旁注连接。先定契约，再测替身，最后另行授权真实小样。

## 验收标准
- [ ] 契约包含来源 ID、精确引文、观察、假设与不确定性；可返回证据不足或零条可靠发现。
- [ ] 检查引文实际存在；错误 ID、虚构引文、无效 JSON 不展示为可靠发现。
- [ ] 用户预览并确认发送范围；示例、草稿、未选记录与凭证不上传。
- [ ] 测试替身明确标识；覆盖成功、空结果、错误、超时、取消、重试和原文被编辑/删除。
- [ ] 无伪造积极结论、诊断或人格标签；不把疲惫自动解释为成长。
- [ ] 不改写或删除日记；真实调用失败不回退成伪 AI 结果。
- [ ] 真实模型测试单独获同意，仅发虚构记录并记录额度风险；未授权标未测。
- [ ] 替身与真实调用报告分开，主 Agent 审核后验收。

## Agent 边界
建议独占 copilot-bridge.mjs 与对应契约测试；前端契约先由主 Agent 确认。
不启动任意工具权限、公开桥接服务或保存模型原始日志；本机入口不宣称离线免费。
