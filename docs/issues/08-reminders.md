## 目标与前置
主应用迁移后，单独验证网页提醒与权限，明确页面关闭时的实际能力。

## 验收标准
- [ ] 开启前请求用户许可，覆盖允许、拒绝、撤回和不支持情况。
- [ ] 设置跨刷新保留，时间/时区明确，页面打开时每日不重复提醒。
- [ ] 用可控测试时钟验证跨日、时间改变和重复页面；不修改电脑系统时钟。
- [ ] 关闭页面后的实际表现被实测并如实说明，不宣传未实现的后台每日提醒。
- [ ] 取消提醒后无新通知；权限失败不影响记录保存。
- [ ] 不在系统通知暴露日记正文；真实系统权限操作需要用户确认。
- [ ] 若可靠后台提醒属于产品要求，单独提出方案，不能用页面定时器冒充。

## Agent 边界
不配置系统自动化，不更改全局通知设置，不创建无关定时任务。
本 issue 不授权发布小程序或 App Store；报告明确浏览器和设备差异。
