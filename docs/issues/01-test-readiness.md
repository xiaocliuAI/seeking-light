## 验收标准
- [ ] 确认浏览器能读取页面、点击、输入和截图；不可用时记录阻塞，不冒报通过。
- [ ] 创建隔离测试配置/上下文，确认不包含用户日记；不清空用户现有存储。
- [ ] 记录代码提交、测试地址、浏览器、视口、时间与数据版本。
- [ ] 准备带标记的虚构记录：空白、单字、多行、长文、疲惫、证据不足、跨日。
- [ ] 重跑 npm test；默认不调用模型，不上传真实日记。
- [ ] 跑通打开页面、保存一条虚构记录、刷新恢复和截图的冒烟测试。
- [ ] 给出可复现启动说明及测试报告；主 Agent 复核后才解除下游阻塞。

## Agent 边界
先读 AGENTS.md、docs/web-test-plan.md。建议只写测试准备文档和独立测试文件；新文件加入白名单。
禁止修改用户数据、模型授权或公开部署配置。工具权限缺失需要人工恢复，不能靠修改页面绕过。
