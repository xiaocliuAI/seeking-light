## 目标与前置
真实 Findings 契约确定并完成接入后，实现跨刷新保留的反馈、可选尝试与回访闭环。

## 验收标准
- [ ] 发现、分析范围和来源版本可追溯，用户反馈不会修改原文。
- [ ] 有点像/不太对、保留/取消尝试状态跨刷新保留，多条发现互不串联。
- [ ] 回访作为完整日记保存，能回到对应发现；日期和计数正确，不重复提交。
- [ ] 允许没有改善、不愿尝试或没有反馈，不把它们记为失败。
- [ ] 来源编辑/删除后明确标记失效，不能继续呈现为有效依据。
- [ ] 存储失败保留输入并允许恢复；覆盖刷新、旧数据和异常场景。
- [ ] npm test 与浏览器全流程通过，用户评估线索是否确实有帮助。

## Agent 边界
写入文件需主 Agent 指定；不得与迁移任务同时写 app.js。
不自动追加模型调用或上传回访；内容分析另需选择与确认。
