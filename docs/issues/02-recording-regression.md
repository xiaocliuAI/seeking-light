## 验收标准
- [ ] 空白不能保存；单字、多行和长文一次各保存一条，原文和换行完全保留。
- [ ] 保存后输入清空、条数只加一；刷新保留记录；草稿恢复且不计数。
- [ ] 日期筛选、取消筛选、热力图和统计一致；示例清楚标记。
- [ ] 主动打开示例发现；所有引文精确对应原文；完整来源和返回定位正常。
- [ ] 有点像/不太对反馈、保留尝试、回访进入时间线并刷新恢复。
- [ ] 两条示例线索的数据互不串联；反馈不改写原文。
- [ ] 输出逐项实际结果与虚构数据截图；失败附复现步骤。

## Agent 边界
使用隔离环境；首次只验收和报告，不边测边做大规模重构。
建议写独立浏览器测试或验收报告，不改 app.js 或 copilot-bridge.mjs。
不把 DOM 替身或固定示例结果声称为真实 AI 验收。
