## 目标与前置
准备 issue 通过后，验证“原文与旁注”的排版与可操作性，而非自动判定审美。

## 验收标准
- [ ] 1440x900、390x844、320x740 的书写、回看、发现均无横向溢出或重叠。
- [ ] 长文输入可读且保存可达；专注模式退出保留原文。
- [ ] 键盘导航、焦点、确认弹窗、200% 缩放可用。
- [ ] 字体加载失败仍可写、可保存，日期和按钮不挤压。
- [ ] 减少动态设置和真实手机软键盘下操作可达；无法测真实手机明确标未测。
- [ ] 真实截图使用虚构数据，不包含私人记录。
- [ ] 用户人工评价书写舒适度、排版美观和发现的可理解性；Agent 不代替用户结论。

## Agent 边界
只读验收优先；样式修复仅在明确分配 output/seeking-light/journal.css 后进行。
UI 修改读取 frontend-design skill，不重开已固定的多套配色探索。
