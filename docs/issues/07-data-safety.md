## 目标与前置
主应用设计迁移后，验收编辑、删除、导出、备份与恢复，保护长期记录。

## 验收标准
- [ ] 编辑旧记录保留原日期、原 ID 和条数；删除明确确认并更新相关发现状态。
- [ ] 导出仅含真实已保存记录，保留完整原文和日期；不含示例、草稿、默认猜测或凭证。
- [ ] 用虚构数据验证导出/恢复及重复导入策略，不要求先删除原数据。
- [ ] 真实浏览器验证持久化与存储异常；无法稳定模拟的真实设备错误标未测。
- [ ] 长期记录和大量数据不导致明显丢失、页面不可操作或计数错误。
- [ ] 对用户明确本地存储、清理浏览器的风险，以及尚无跨设备同步。
- [ ] 只交付去隐私报告；私人导出、截图、模型内容不进 Git。

## Agent 边界
不读取或清空真实日记；备份设计先经主 Agent 复核。
真实设备和大量数据测试需隔离环境，不能把虚构记录混进用户日记。
