# 寻光日记：原文与旁注

2026-11-07，首轮统一设计和完整流程体验稿。不是正式应用替换。

## 固定设计

- 纸白 #FFFFFF：书写与原文的连续页面。
- 雾灰 #EEF3F2：应用顶部，不用浮动卡片拼接页面。
- 墨色 #283638：原文主色。
- 孔雀青 #175F65：品牌、保存、选中导航。
- 莓红 #92344C：旁注、来源定位，不表达成长评分。
- 浅金 #F5D883：仅标记发现引用的原文。
- 霞鹜文楷：品牌与用户原文；系统无衬线：导航、日期、数字和模型解释。
- 日期轴固定 96px，主原文沿同一条轴线左对齐；手机日期移到原文上方。
- 输入、回看和发现共用原文样式；发现是原文旁注，不另造一套卡片系统。
- 不把照片或插画当作美观的支撑，不要求日记内容有文采。

## 审视与取舍

辨识度来自稳定的“日期 / 原文 / 旁注”关系，不来自每日自动高亮。
大面积绿色、深色输入卡片、名言式页标题和装饰封面不采用。
书写区允许单字、长文与保留换行；没记录不表现为失败。
足迹表达条数，不宣称心理状态或成长。
示例恢复线索和兴趣线索互相独立，不能把所有日常解释为工作能力。

## 体验流程

自由输入 -> 独立保存 -> 回看原文 -> 主动查看示例发现 -> 定位证据 ->
给线索反馈 -> 可选保留尝试 -> 写下尝试结果 -> 结果回到原文时间线。

## 数据和调用边界

文件：独立的静态体验稿，不改变主应用和 Copilot bridge。
存储键：seeking-light-layout-prototype-v1，不读写 seeking-light-journal-v5。
所有预置记录是虚构示例；用户新输入不参与固定的示例发现。
不发送记录，不调用模型，不消耗 Copilot 额度。
真实模型分析、通知权限和跨设备同步尚未验收。
